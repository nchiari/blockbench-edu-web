# Texturas del huevo generador

Copias sin modificar de `textures/items/spawn_egg.png` y `textures/items/spawn_egg_overlay.png` del Vanilla Resource Pack 1.26.30 local.

La vista previa de `blockbench_edu.js` incluye estos mismos PNG como datos embebidos para funcionar también como plugin. Tiñe las dos capas por separado con composición `multiply`, restaura su transparencia con `destination-in` y superpone el detalle sobre la base, como el componente `colored-spawn-egg` del Minecraft Entity Wizard de Blockbench.

Fuente del Wizard consultada: https://github.com/JannisX11/blockbench-plugins/blob/master/plugins/minecraft_entity_wizard/minecraft_entity_wizard.js
